# 📅 Calendar App

A modern, responsive, and interactive **Calendar Web Application** built using cutting-edge frontend technologies. This project provides a clean UI and smooth user experience for managing dates, events, and schedules.

---

## 🚀 Features

- 📆 Interactive calendar UI
- 🧭 Easy navigation between months
- 📝 Add and manage notes/events
- 🎨 Clean and modern design
- ⚡ Fast performance with optimized rendering
- 📱 Fully responsive (mobile + desktop)
- ⌨️ Keyboard accessibility support
- 🧩 Modular and scalable code structure

---

## 🛠️ Tech Stack

- **Frontend:** React / Next.js  
- **Language:** TypeScript / JavaScript  
- **Styling:** Tailwind CSS / CSS Modules  
- **Animation:** Framer Motion

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/Hunterx15/Calendar.git
cd Calendar
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open in browser:

```
http://localhost:5173
```
